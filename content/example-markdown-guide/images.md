# Images

## An image in this repository

Keep images next to the pages that use them, and link them relatively. The
site loads them from GitHub at the version it synced.

![A GOV.UK blue panel, as an example image](images/example-panel.png)

## An image published elsewhere

Use the full `https://` address. The site allows images from that address only
on pages that use one.

![Cloud service models: software, platform and infrastructure as a service](https://assets.publishing.service.gov.uk/media/67ebaf607112777ed84f8151/s960_Cloud-service-models-diagram.png)

Always describe the image in the brackets: it is what a screen reader reads,
and what shows if the image does not load.
