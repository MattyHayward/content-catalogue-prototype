# Text

The page's `#` heading is its title. The site shows it in the page's own
heading, so write it once, at the top.

## Headings

Use `##` for the page's main sections and `###` within them. Each one becomes
an anchor that can be linked to, and the `##` and `###` headings make up the
contents list at the top of the page.

### A third-level heading

#### A fourth-level heading

Use these sparingly: the contents list only shows the first two levels.

## Emphasis

Use **bold** for words that must not be missed, like **must** and **should**
in a standard. Use *italics* rarely: GOV.UK style avoids them. Use `code` for
anything the reader types or reads in a terminal.

## Paragraphs and breaks

A blank line starts a new paragraph. A line break within a paragraph is
ignored, so write one sentence per line if it makes changes easier to review.
