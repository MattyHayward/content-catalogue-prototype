# Linking

## To another page in this guide

Link to the page's Markdown file, relative to this one:
[Lists](lists.md), or [Callouts](../callouts.md). The site points the link at
the page here, and the link works on GitHub too.

## To a heading

Link to a heading's anchor, on this page or another:
[back to the top section](#to-another-page-in-this-guide), or
[Headings on the Text page](text.md#headings). Anchors are the heading in
lower case, with spaces as hyphens.

## To somewhere else

Use the full `https://` address:
[the GOV.UK Service Manual](https://www.gov.uk/service-manual).

## Reference-style links

For a long paragraph, put the addresses at the end, as in the
[Service Standard][] and the [Technology Code of Practice][tcop].

[Service Standard]: https://www.gov.uk/service-manual/service-standard
[tcop]: https://www.gov.uk/guidance/the-technology-code-of-practice
