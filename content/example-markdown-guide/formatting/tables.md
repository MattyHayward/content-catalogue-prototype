# Tables

Write a table with pipes, a header row and a line of dashes. Colons in the
dashes line align a column.

| Layout | Used by | Numbered |
| --- | --- | :---: |
| requirements | standard, principles | yes |
| policy | policy | sections |
| guide | guidance, strategy | no |
| steps | method | yes |

Start a cell with `#` to make it the row's heading, which helps screen reader
users in a wide table:

| Point | What it asks |
| --- | --- |
| # 1 | Define user needs |
| # 2 | Make things accessible and inclusive |

A wide table scrolls sideways on a narrow screen rather than squashing.
