# Lists

## Bulleted lists

Introduce a list with a sentence that ends in a colon:

- start each item with a hyphen
- write items in lower case, without full stops
- nest an item by indenting it two spaces:
  - like this one
  - and this one

## Numbered lists

Use numbers when the order matters:

1. Write the first step.
2. Write the second step.
3. Keep going: the site numbers them, whatever numbers you type.
